  1-  Élan Fitness : 

        Projet de site web pour la salle Élan Fitness, située à Casablanca.
       
  2- Description : 

        Le site présente la salle Élan Fitness, , ses programmes (musculation, yoga,cardio, boxe fitness) 
        et propose une page de contact avec un formulaire et une carte Google Maps.

  3- Pages du site :

        - index.html : page d'accueil.
        - apropos.html : présentation de la salle et de l'équipe.
        - programmes.html : liste des cours proposés.
        - contact.html : formulaire de contact et carte Google Maps.      
        
  4- les ressources :

        - https://www.w3schools.com/              
        - https://openclassrooms.com/
        - https://nouvil.net/

  5-  - Technologies utilisées : 

        - HTML : structure des pages web.
        - CSS3 :  Design du site.
        - Google Maps : affichage de la localisation de la salle.
